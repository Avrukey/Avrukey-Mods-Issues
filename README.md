# Avrukey Mods — Issue Tracker

This is the public issue tracker for all Minecraft mods created by Avrukey.

Use this repository to:

- Report bugs and crashes
- Report incorrect mod behavior
- Report rendering or compatibility problems
- Suggest improvements and new features

## Before reporting a bug

Make sure that:

- The mod was downloaded from its official CurseForge or Modrinth page
- The mod file matches your Minecraft version and mod loader
- All required dependencies are installed
- The same problem has not already been reported

## Creating a report

Open the [issue form](https://github.com/Avrukey/Avrukey-Mods-Issues/issues/new/choose) and select the appropriate report type:

- **Bug report** — crashes, broken features, rendering problems, or incorrect behavior
- **Feature request** — suggestions for new features or improvements

Please include logs, crash reports, screenshots, and reproduction steps whenever possible.
